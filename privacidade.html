Política de Privacidade

Postador Canais é uma ferramenta de uso pessoal. Ela é usada somente pelo autor, para enviar, agendar e consultar os números dos vídeos dos canais dele no YouTube.

Dados acessados

Com a autorização do próprio dono da conta, a ferramenta usa a API do YouTube para enviar vídeos, definir título, descrição, playlist e horário de publicação, e ler estatísticas dos próprios canais.

Uso e armazenamento

Os dados ficam apenas no computador do autor. Nada é vendido, compartilhado com terceiros ou usado para publicidade. O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

Dados de outras pessoas

A ferramenta não coleta nem armazena dados de outros usuários.
